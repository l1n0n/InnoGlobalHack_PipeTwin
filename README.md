# InnoGlobalHack_PipeTwin

Linar, Max, Igor, Sasha

Хакатон Nedra Digital, **кейс 1 (прогноз между ВТД)**. Для каждого 10-метрового сегмента участка
`1250022871` (направление DIR-2) прогнозируем минимальную остаточную толщину стенки на дату ВТД 2023-12-01.

## Запуск

```bash
uv sync
uv run python main.py      # шаги 1–7, около 5 с (первое чтение xlsx около 3 с, дальше берётся parquet-кэш)
uv run pytest -q           # проверка формата result.csv
```

Результат: `result.csv` (`id,segment_id,thickness_pred`, 525 строк). Отчёты лежат в `reports/`.

## Этапы (`src/`)

| файл | что делает |
|---|---|
| `config.py` | константы (T_DATE, участки, номинал 8.0 мм, сегмент 10 м, seed 42) |
| `load.py` | чтение листов `all.xlsx` (calamine) и кэш в `data/cache/*.parquet` |
| `clean.py` | очистка ВТД, результат в `vtd_clean.parquet` |
| `segment.py` | сетка сегментов 0..floor(L/10), цель `min_thk` и флаг `censored` |
| `features.py` | одна строка на переход «ВТД_prev → ВТД_next»: толщина/глубина/число дефектов, соседи ±2, историческая скорость, рельеф, режим за окно |
| `train.py` | базовые решения и CatBoost, валидация, `metrics.csv`, `importance.csv` |
| `predict.py` | обучение на всех переходах, прогноз, `result.csv`, `intervals.csv` (p10/p50/p90), `top10_dangerous.csv` |
| `plots.py` | `validation_scatter.png`, `profile_1250022871.png` |

Модель предсказывает потерю толщины `loss = thk_prev − thk_next` (обрезана снизу нулём),
итоговый прогноз считается как `thk_prev − loss_pred`. Интервалы дают квантильные CatBoost (α = 0.1 и 0.9),
обученные на необрезанной дельте.

## Метрики (r² = квадрат корреляции Пирсона)

| подход | 2018→2022 ⇒ 2022→2023 (55 сегм.) | GroupKFold, блоки 500 м (635) |
|---|---|---|
| persistence | **0.598** | 0.149 |
| линейная экстраполяция | 0.474 | 0.152 |
| Ridge | 0.250 | 0.158 |
| **CatBoost** | 0.492 | **0.198** |

Покрытие p10–p90 на временной валидации: 0.58 без калибровки, после расширения вокруг p50 с коэффициентом k = 1.5 стало 0.80
(k подбирается в `train.py`, затем применяется в `predict.py`).

Главные признаки: `thk_prev`, `censored_prev`, `max_depth_prev`, `n_defects_prev`.

### Эксперименты (`reports/experiments.csv`)

| шаг | изменение | оставлено | r² CatBoost temporal | r² CatBoost GKF |
|---|---|---|---|---|
| 0 | базовая версия | – | 0.188 | 0.185 |
| 1 | выравнивание прогонов 2022→2023 на −1 сегмент | да | 0.475 | 0.197 |
| 2 | rolling min/mean `thk_prev`, окно ±1 | нет | 0.440 | 0.197 |
| 3 | `sample_weight = 0.3` для переходов 2018→2022 | да | 0.492 | 0.198 |
| 4 | калибровка интервалов (k = 1.5) | да | 0.492 | 0.198 |

На временной валидации после выравнивания persistence (0.598) обгоняет CatBoost (0.492). Ранжирование в основном
определяется `thk_prev`, а модель потерь на 55 сегментах добавляет шум. На GroupKFold CatBoost остаётся лучшим.

Временная валидация идёт на других участках (9490, 11604), потому что для 22871 прогона 2023 года нет.

## Очистка ВТД

- Берём только потерю металла: `trait == "Потеря металла"` или (2018, пустой `trait`) `Feature Description`, начинающееся с «потеря металла». Вмятины, швы и арматура исключены, `is_beyond_pot == True` тоже.
- 2018: `Defect Depth in %` записана в долях, умножаем на 100.
- Пустая `Residual Wall Thickness` заполняется как `8.0 · (1 − depth%/100)`.
- `Defect Type` приведён к виду «Внутренний» / «Внешний».
- Дефекты с `Distance` больше длины участка (у 11604 есть до 501 м при L = 493.4) относим к последнему сегменту.

## Допущения

- Сегмент без дефектов в отчёте ВТД считается толщиной 8.0 мм (порог регистрации 10 %), флаг `censored = 1`.
- Толщина не растёт между прогонами: цель `loss` обрезана снизу нулём (рост считаем шумом выравнивания).
- Прогоны 2018 и 2022 выровнены (лучший сдвиг 0). Прогон 2023 сдвинут относительно 2022 примерно на +8 м: на 9490 и 11604 r² толщин 2022[s−1] и 2023[s] равен 0.58, без сдвига 0.17, и на обеих половинах 11604 сдвиг одинаковый. Поэтому для переходов 2022→2023 и 2022→T признаки прогона 2022 сдвигаются на 1 сегмент (`RUN_SHIFT` в `config.py`). Предполагаем, что у 22871 в прогоне 2023 такой же сдвиг.
- Режим работы одинаков по всей длине участка (данные есть только на уровне участка), берём только даты ≤ T_DATE.

## Найденные аномалии

- **УЗТ**: для DIR-2 всего 64 замера (2016, 2020) со значениями 12.6–15.9 мм при номинале 8 мм. Вероятно, это другая труба или другой датчик, поэтому в модель не берём.
- **`sample_result`** содержит данные купонов УКК, а не шаблон ответа, и не используется.
- **Сдвиг выявляемости между прогонами**: в 2018 на 22871 найдено 2 255 дефектов, а в 2022 уже 25 989; доля «чистых» сегментов упала с 37 % до 3 %. Часть «потери» 2018→2022 объясняется чувствительностью прибора, а не коррозией.
- **Шум выравнивания**: у 22–33 % сегментов следующий прогон показывает толщину *больше* предыдущей.
- **Режим потока**: расслоенного режима в данных нет (только «Турбулентный»/«Переходный»), поэтому используем долю нетурбулентных суток.
