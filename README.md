# InnoGlobalHack_PipeTwin

## Структура проекта

- `frontend/` — HTML, CSS и JavaScript веб-интерфейса.
- `backend/pipeline_data.py` — импорт паспортов, ВТД, УЗТ и профилей CSV.
- `backend/forecasting.py` — расчёт остаточной толщины для двух кейсов.
- `backend/corrosion.py` — модель CO₂-коррозии и расчёт утонения.
- `backend/validation.py` — историческая проверка и метрики.
- `backend/submission.py` — проверка и сборка `result.csv`.
- `backend/web_api.py` — маршруты FastAPI и раздача фронтенда.
- `pipeline_forecast.ipynb` — запуск, экспорт и графики.
- `docs/calculation-methods.md` — описание расчёта и его ограничений.
- `tests/` — синтетические данные для двух труб.

## Локальный интерфейс

**Раздельный запуск на Windows.** Запустите оба файла двойным щелчком:

1. `Start Backend.cmd` — API и [документация](http://127.0.0.1:8000/docs).
2. `Start Frontend.cmd` — интерфейс на [127.0.0.1:5173](http://127.0.0.1:5173).

Оставьте оба окна открытыми. Для остановки нажмите `Ctrl+C` в каждом окне.

**Быстрый запуск на Windows.** Дважды щёлкните `Start PipeTwin.cmd` в корне
проекта и откройте [127.0.0.1:8501](http://127.0.0.1:8501). Чтобы остановить
сервер, нажмите `Ctrl+C` в окне запуска.

Для установки зависимостей откройте PowerShell из корня проекта. Создайте окружение с помощью
установленного CPython для Windows. Если `.venv-demo` уже создано,
начните с установки зависимостей.

Для сценария NORSOK M-506 установите 64-битную Java 17 или новее и укажите
каталог установки в `JAVA_HOME`. NeqSim запускает JVM при первом расчёте CO₂.

```powershell
py -3 -m venv .venv-demo
.\.venv-demo\Scripts\python.exe -m pip install -r requirements.txt
```

Чтобы запустить веб-приложение вручную, выполните:

```powershell
.\.venv-demo\Scripts\python.exe -m uvicorn backend.web_api:app --host 127.0.0.1 --port 8501
```

Откройте [127.0.0.1:8501](http://127.0.0.1:8501). Загрузите `data/vtd.csv`
(около 21 МБ), если есть замеры, или `data/passport.csv` для сценария без ВТД.
Для примера также подходит сокращённый `tests/passport.csv` со столбцами
`id,length_m,nominal_thickness_mm,commissioned_at`.
Также принимаются `data/uzt.csv` и профиль PipeTwin
со столбцами `id,segment_id,thickness_pred`. Выберите трубу из файла, чтобы увидеть
профиль толщины и таблицу 10% самых тонких сегментов
с округлением числа сегментов вверх. Кнопка выгружает прогноз по всем трубам.
Приближайте участок колёсиком мыши, перемещайте график перетаскиванием и
возвращайтесь к исходному масштабу двойным щелчком. Наведение показывает значения.

Для ВТД показываются отдельные точки остаточной толщины в порядке записей
последней доступной даты. При необходимости перед загрузкой задайте дату среза.
Сырые дистанции не используются для объединения прогонов или расчёта скорости.
Поиск принимает номер точки или `row:123` для исходного `row_id`.
Для УЗТ используются стационарная координата `start_distance` и
`residual_wall_thickness`. Лимит загрузки составляет 50 МБ.

Без ВТД для каждого участка создаётся профиль из номинальной толщины паспорта.
Исходная дата — ввод в эксплуатацию. Укажите дату прогноза либо горизонт до
100 лет, затем задайте скорость или параметры NORSOK M-506. Для участка
`1250009583` паспорт задаёт 4,5 мм и дату 20.06.1993. Для случая с ВТД
`1250022871` дата среза 31.12.2022 выбирает записи от 06.07.2022.

На вкладке **«Замена участка»** укажите первый и последний сегменты, дату,
толщину и наружный диаметр новой трубы. Дополнительно можно записать марку
стали, покрытие и примечание. В расчётах новая стенка становится исходной
для заменённых сегментов. Оценка утонения по старым замерам для них не применяется.
Кнопка **«Сохранить профиль CSV»** записывает нормализованный профиль с новыми
параметрами. Исходная толщина, дата замера и историческая скорость сохраняются
в отдельных полях. Для продолжения работы загрузите сохранённый профиль.
Замена доступна для профилей с физическими сегментами.

Фронтенд работает
без сборки. Браузер загружает библиотеку Plotly.js с CDN. Вкладка «Сценарий коррозии» показывает толщину по годам
и время до заданного порога. Скорость можно взять из истории ВТД, ввести вручную
или вычислить с помощью [NORSOK M-506 в NeqSim](https://equinor.github.io/neqsimhome/javadoc/site/apidocs/neqsim/process/corrosion/NorsokM506CorrosionRate.html)
для внутренней CO₂-коррозии углеродистой стали в присутствии свободной воды.
Задайте температуру, абсолютное давление, молярную долю CO₂ в процентах,
pH водной фазы, скорость потока и внутренний диаметр. При постоянных условиях толщина уменьшается
линейно до нуля. Расчёт предназначен для сравнения сценариев. Загруженные файлы
обрабатываются в памяти.
Предыдущий прототип на Streamlit и pywebview находится в `frontend/legacy/`.
Для его запуска используйте `python frontend/legacy/desktop.py` из окружения демо.

## Файл для жюри

По заданию сдаётся **`result.csv`** с заголовком
`id,segment_id,thickness_pred`. Толщина прогнозируется на дату T в миллиметрах.
Для каждого из двух участков требуется одна строка на физический 10-метровый
сегмент. Нумерация начинается с нуля: `segment_id = floor(дистанция_от_начала / 10)`.

На сайте откройте вкладку **«Экспорт»**. Можно загрузить готовый прогноз и
нажать **«Использовать загруженный прогноз»**. Либо настройте сценарий для
каждого из двух участков, по одному нажмите **«Добавить прогноз участка в
result.csv»**, затем нажмите **«Собрать result.csv»**. График читает полученный
CSV, а **«Скачать result.csv»** сохраняет тот же файл. Если длина известна,
проверяется покрытие до последнего сегмента. Для участка без длины проверяется
непрерывность нумерации. Для кейса между ВТД исходные записи должны быть
пространственно привязаны к физическим сегментам. Нумерация строк сырого ВТД
для сдачи не подходит.

## Запуск расчёта в Jupyter

Jupyter позволяет показать ход расчёта на защите, менять условия и повторять
эксперимент. Ноутбук вызывает ту же функцию скорости CO₂-коррозии, что и API.
Из корня проекта после установки основных зависимостей выполните:

```powershell
.\.venv-demo\Scripts\python.exe -m pip install jupyterlab matplotlib
.\.venv-demo\Scripts\python.exe -m jupyterlab pipeline_forecast.ipynb
```

Если ноутбук уже был открыт до обновления кода, перезапустите ядро Jupyter.
Выберите **Run → Run All Cells**. По умолчанию ноутбук строит базовый прогноз
для участков `1250022871` (525 сегментов) и `1250009583` (1 475 сегментов),
записывает `result.csv` в корне проекта и показывает оба профиля из этого файла.
При `target_date = None` используется общая последняя дата в режимных данных
(24.11.2024). Для сдачи укажите подтверждённую дату T в `target_date`.

[Методы расчёта и историческая проверка](docs/calculation-methods.md).

В режиме `demo_mode = True` ноутбук читает
`tests/result.csv`, записывает `result_demo.csv` и строит графики обеих труб
прямо под ячейкой. Для готового прогноза задайте `demo_mode = False`,
укажите входной CSV в `real_source` и при необходимости измените `passport`. Если
во входном файле больше двух участков, задайте `submission_ids`. Режим
`use_precomputed_result = False` рассчитывает сценарий по входной толщине.
Для запуска без NeqSim задайте `manual_rate` в мм/год.

## Реальные данные

Паспорт описывает 16 простых участков, 4 основных участка и 3 направления
OISPIPE. Восемь участков относятся к внутрипромысловым нефтесборным
трубопроводам от ЗУ до ДНС, ещё восемь — к межпромысловым напорным
нефтепроводам от ДНС до ЦПС.

| Файл | Покрытие и дополнительные параметры |
| --- | --- |
| `passport.csv` | Все 16 участков. Номинальная стенка, диаметр, длина, характеристики материала и иерархия сети. |
| `profile.csv` | Все 16. Координаты, отметки высоты и дистанция для карты, продольного профиля и анализа низких точек. |
| `regime.csv` | Все 16. История температуры, давления, скорости, обводнённости, плотности и вязкости. Перед расчётом по режимам нужно подтвердить единицы и сопоставить даты. |
| `vtd.csv` | 15 участков. Остаточная толщина, классификация дефектов, размеры и поля рекомендаций по ремонту. |
| `uzt.csv` | 3 участка. Точечные замеры и углы. УЗТ может дать профиль для участка без ВТД при отдельной загрузке. |
| `repcorr_south.csv` | По ID с паспортом совпадает 1 участок (83 записи). В журнале есть измеренные скорости, pH и данные по ингибиторам. `CO2 in Water Phase` относится к водной фазе, а для формы NeqSim требуется молярная доля CO₂ в газовой фазе. |

В паспорте простые ID записаны с суффиксом `.0`, в ВТД, УЗТ, профиле и
режиме — целыми числами. В интерфейсе импортируются паспорт, ВТД и УЗТ.
Локальный паспорт также используется для отображения названий участков по ID.
Профиль трассы и режим не подставляются автоматически в расчёт NeqSim.

## Тестовые данные

В `tests/` лежат синтетические CSV с сокращённой схемой для двух сценариев.
У `TEST-01` есть два прошлых ВТД и замеры УЗТ. У `TEST-02` есть паспорт,
профиль и технологический режим. Его последний сегмент имеет длину 5 м.
У обеих труб есть режим за семь дней.

`tests/result.csv` содержит 19 строк с демонстрационным прогнозом
в формате `id,segment_id,thickness_pred`. Этот CSV можно загрузить вручную.
Значения заданы для проверки отображения и выгрузки. Обучение модели в приложение
не входит.
