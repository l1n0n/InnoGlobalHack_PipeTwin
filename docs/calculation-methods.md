# Расчёт остаточной толщины PipeTwin

## Вход и результат

Прогноз строится на дату T для каждого физического 10-метрового сегмента.
`segment_id = floor(дистанция от начала участка / 10)`.
Файл `result.csv` содержит `id,segment_id,thickness_pred`, где толщина
измеряется в миллиметрах. В текущем файле 525 сегментов участка `1250022871`
и 1 475 сегментов участка `1250009583`.

## Базовый прогноз

Остаточная толщина равна `max(0, исходная толщина − скорость × время)`.
Время переводится из дней в годы делением на 365,25. Общая скорость
**0,1021 мм/год** оценена по разнице между паспортным номиналом и медианой
сегментных минимумов первого ВТД от 23.09.2018 с учётом времени от ввода.

- **Между ВТД, `1250022871`.** Исходная толщина — минимум замеров по
  сегменту на ВТД от 06.07.2022. Для укладки этого прогона на сетку
  применяется `Distance_adjusted`. Дефекты разных прогонов по координате
  не сопоставляются. Для 17 сегментов без замера применена линейная
  интерполяция между соседними измеренными сегментами. На краях используется
  ближайший замер.
- **От ввода без ВТД, `1250009583`.** Исходная толщина — паспортные
  4,5 мм на 20.06.1993. Общая скорость перенесена с первого участка,
  поэтому прогноз одинаков по всей трубе.

## Историческая проверка

Прогноз на 06.07.2022 строится из данных на 23.09.2018. Замеры 2022 года
используются для оценки. В сравнении 508 сегментов, из них 321 имеет замеры
в обоих ВТД. Горизонт составляет 3,78 года.

| Метод | Pearson r² | MAE, мм | RMSE, мм |
| --- | ---: | ---: | ---: |
| Сохранить толщину прошлого ВТД | 0,082 | 0,497 | 0,641 |
| Вычесть линейное утонение | 0,082 | 0,636 | 0,781 |
| От ввода без локальных замеров, на той же проверочной трубе | Не определён | 0,649 | 0,744 |

Линейное утонение не улучшило Pearson r² и увеличило ошибку в миллиметрах.
Для постоянного прогноза Pearson r² не определён. Доступный набор содержит
проверку на одном горизонте для участка `1250022871`.

## Границы применения

В текущем файле используется предварительная дата 24.11.2024 — общая
последняя дата в файле режима. Для сдачи укажите подтверждённую дату T.
Параметры технологического режима пока не участвуют в оценке скорости.
Привязка ВТД по неподвижным реперам требует отдельной проверки.
NORSOK M-506 доступен как отдельный сценарий CO₂-коррозии.

Запуск расчёта, экспорт и график «прогноз — факт» находятся
в [pipeline_forecast.ipynb](../pipeline_forecast.ipynb).
